Overview : This portfolio includes two coursework extensions and one personal project. Each item has a runnable code.


1.1 MIPS Mini Game: Ice Girl & Fire Boy

Summary

•	A two player puzzle in MIPS assembly (MARS). Two characters must reach the exit; Ice Girl passes ice tiles, Fire Boy passes fire tiles.

•	Controls: Ice Girl (W/A/D), Fire Boy (J/L/I), R = restart.

Tech/Skills

•	MIPS assembly (MARS), state machine loop, input handling, basic collision.




1.2 Java (Greenfoot) Game: Spacecraft vs Asteroids

Summary

•	A simple 2D arcade game built in Java using Greenfoot. Pilot a spacecraft, avoid/ shoot asteroids with bullets, score points, lose lives on collision.

Tech/Skills

•	Java OOP, Greenfoot framework, collision detection, basic game loop.



2.1 C++ Salary Calculator (Web UI)

Summary

•	A lightweight local web app to calculate daily and monthly pay for part time job. Stores entries in CSV; supports flexible time formats and overnight shifts.

Tech/Skills

•	C++17, , HTML frontend, CSV persistence.


Notes 

•	All demos recorded on a personal machine; code intended for educational/portfolio use.
